# Git DevOps Project - Task Documentation

## Objective

Demonstrate Git and GitHub version-control best practices.

## Tools Used

* Git
* GitHub
* PowerShell

## Branching Strategy

* main - stable branch
* dev - development branch
* feature/\* - feature development

## Tasks Completed

* Git repository initialization
* Branch creation
* Feature branch development
* Pull Requests
* README documentation
* .gitignore
* Git tags
* GitHub repository

## Git Workflow

feature → dev → main

Changes are developed in feature branches, reviewed using Pull Requests,
merged into dev, and finally merged into main.







\## Version Control Best Practices



The project follows a feature-branch workflow where changes are developed

in separate branches and reviewed through Pull Requests before merging.
